\# Security Automation Engineering Portfolio



Welcome to my Security Operations and Automation portfolio. I am a Cybersecurity Engineer certified in \*\*Microsoft SC-900\*\* and \*\*Cisco CCST\*\*, specializing in Python-based automation, threat detection, and incident response. 



This repository contains enterprise-grade security tools designed to automate SOC workflows, enforce data integrity, and streamline threat intelligence. All projects align with \*\*CompTIA Security+\*\* (SY0-701) framework objectives.



## 📁 Repository Contents

| Project Name | Security Domain | Description |
| :--- | :--- | :--- |
| **[01_File_Integrity_Monitor](./01_File_Integrity_Monitor/)** | Cryptography & Data Integrity | A Host-Based Intrusion Detection System (HIDS) that uses SHA-256 hashing to establish baselines and detect unauthorized file tampering. |
| **[02_System_Log_Analyzer](./02_System_Log_Analyzer/)** | Security Operations (SIEM) | An automated regex-based log parser that ingests Linux authentication logs to detect and alert on SSH Brute-Force attacks. |
| **[03_Threat_Intel_Integrator](./03_Threat_Intel_Integrator/)** | Threat Intelligence & API | A SOAR script that connects to external REST APIs to enrich suspicious IP telemetry with automated risk triage. |
| **[04_Network_Port_Scanner](./04_Network_Port_Scanner/)** | Network Reconnaissance | A multi-threaded TCP port scanner utilizing thread pooling for rapid attack surface auditing. |
| **[05_Incident_Response_Responder](./05_Incident_Response_Responder/)** | Incident Response & SOAR | An automated IR playbook simulator that executes host containment, artifact logging, and forensic audit trails. |
| **[06_Compliance_Auditor](./06_Compliance_Auditor/)** | Configuration & Hardening | An automated system auditor that checks runtime security, permission constraints, and generates a compliance score. |
\## 🚀 How to Use This Repository

Recruiters and Engineers can explore each folder individually. Each project contains:

1\. The functional Python source code.

2\. Simulated enterprise data (logs, target directories) for immediate testing.

3\. A dedicated `README.md` detailing the security concepts, architecture, and exact usage instructions.



\*Feel free to clone this repository and test the automation scripts in a safe sandbox environment.\*
