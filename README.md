\# Security Automation Engineering Portfolio



Welcome to my Security Operations and Automation portfolio. I am a Cybersecurity Engineer certified in \*\*Microsoft SC-900\*\* and \*\*Cisco CCST\*\*, specializing in Python-based automation, threat detection, and incident response. 



This repository contains enterprise-grade security tools designed to automate SOC workflows, enforce data integrity, and streamline threat intelligence. All projects align with \*\*CompTIA Security+\*\* (SY0-701) framework objectives.



\## 📁 Repository Contents



| Project Name | Security Domain | Description |

| :--- | :--- | :--- |

| \*\*\[01\_File\_Integrity\_Monitor](./01\_File\_Integrity\_Monitor/)\*\* | Cryptography \& Data Integrity | A Host-Based Intrusion Detection System (HIDS) that uses SHA-256 hashing to establish baselines and detect unauthorized file tampering. |

| \*\*\[02\_System\_Log\_Analyzer](./02\_System\_Log\_Analyzer/)\*\* | Security Operations (SIEM) | An automated regex-based log parser that ingests Linux authentication logs to detect and alert on SSH Brute-Force attacks. |

| \*\*04\_Network\_Port\_Scanner\*\* | \*In Development\* | Multi-threaded attack surface auditing. |



\## 🚀 How to Use This Repository

Recruiters and Engineers can explore each folder individually. Each project contains:

1\. The functional Python source code.

2\. Simulated enterprise data (logs, target directories) for immediate testing.

3\. A dedicated `README.md` detailing the security concepts, architecture, and exact usage instructions.



\*Feel free to clone this repository and test the automation scripts in a safe sandbox environment.\*
